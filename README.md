# HEATTRANSFER

created by Manuel Rexer.

## Description

This software was used in the phd thesis of Manuel Rexer "Transienter Wärmeübergang in zyklisch belasteten Gasspeichern" (2024).
The Software loads experimental data generated from harmonic characerisations of different gas accumulators, such as air springs or hydraulic accumulators.
The then it analyses the heattransfer in frequency domain to get komplex Nusselt Numbers.
Fom this results a grey box model can be derived. Experimental data is available with open access.

The software is written in MATLAB R2021b. The curvefitting Toolbox is required.

## Content

The main script to calculate komplex Nusselt numbers as well as dimensionless Stiffness is:
code_230223_evaluate_heattransfer_FFT.m
This also saves the results in a matlab table.

code_230428_Semiempiric_Model.m is used to determine the greybox model for komplex Nusselt numbers depending on dimensionless excitation frequency, the Peclet number.

The folder plot_scripts contails several scripts to plot the results from the results table generated by the main script.

## Prerequisites

There are a few adaptions that must be made so that the code runs: 

- one need access to the metadata hub via a personal access token wirtten in "\fst-rdf-utilities\EXAMPLE.config.json"
- depending on the used fluids the .hdf5 files of fluids physical properties must be added in the \substances directory
- one need to install curve fitting toolbox
